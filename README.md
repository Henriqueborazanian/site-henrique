# Site Henrique Stehlik Borazanian

Este é o site pessoal de Henrique Stehlik Borazanian, vendedor comercial especializado no setor vidreiro, representando a empresa Glassparts.

## 🔗 Acesso ao site

Assim que publicado no GitHub Pages, você poderá acessar o site pelo link:

```
https://seu-usuario.github.io/site-henrique
```

## 📦 Conteúdo do repositório

- `index.html` → página principal
- `images/` → pasta com fotos pessoais, logo da Glassparts e banner
- `style` → CSS embutido no HTML

## 🚀 Como publicar no GitHub Pages

1. Faça upload de todos os arquivos neste repositório.
2. Vá em **Settings > Pages**.
3. Configure para `Deploy from branch: main` e `/ (root)`.
4. Acesse o link gerado para ver o site online.
